# 🦇 Ficha Editável: Justice League Unlimited RPG

Este repositório hospeda uma **Ficha de Personagem Interativa e Inteligente** para o sistema de RPG **Justice League Unlimited (JLU)**.

Desenvolvida como uma **Single Page Application (SPA)**, esta ferramenta funciona diretamente no navegador (PC e Mobile), servindo como um "Batcomputador" pessoal para criação e gestão de heróis.

## ⚡ Funcionalidades de Alta Tecnologia

### 🧠 Automação & Regras
* **Calculadora de PAX em Tempo Real:** O sistema calcula automaticamente o custo de Atributos (5 PAX a cada +3) e soma os custos de Poderes e Equipamentos.
* **Validação de Tiers:** Ao alterar o Nível de Ameaça (D, C, B, A, S), a ficha ajusta automaticamente os limites de atributos e graus de poder, alertando visualmente (vermelho/laranja) caso alguma regra seja quebrada.
* **Lógica de Origem:** Ao selecionar "Kryptoniano", os bônus de atributo são aplicados automaticamente.

### 📚 Banco de Dados Integrado (Fastplay)
* **Lista Completa de Habilidades:** Não é necessário digitar tudo. Um menu suspenso contém todos os **Super Poderes, Treinamentos Marciais, Tecnologias, Perícias e Traços** do livro básico.
* **Referências de Página:** Cada item selecionado indica a página exata do livro para consulta rápida de regras.
* **Arsenal Completo:** Lista de Armas, Armaduras e Apetrechos (Gadgets) com seus respectivos custos pré-configurados.

### 🖥️ Interface & Usabilidade
* **Design "Torre de Vigilância":** Interface imersiva em Modo Escuro (Dark Mode) com elementos neon e tipografia oficial.
* **100% Responsivo:** O layout se adapta perfeitamente a telas de **Celular** (colunas empilhadas, botões maiores) e **Desktop**.
* **Campos Expansíveis:** As áreas de texto (Histórico, Descrição de Poderes) crescem infinitamente conforme você digita, garantindo que nenhuma informação seja cortada.

### 💾 Sistema de Save/Load
* **Salvar Dossiê:** Exporte a ficha completa do seu herói em um arquivo `.json`.
* **Carregar Dados:** Importe o arquivo para continuar a edição de onde parou ou para subir de nível entre sessões.

### 🖨️ Impressão Inteligente
* **Modo PDF Full Dark:** Ao imprimir ou salvar como PDF, o sistema força o navegador a manter o fundo escuro e as cores da interface, gerando um documento digital de alta fidelidade visual.
