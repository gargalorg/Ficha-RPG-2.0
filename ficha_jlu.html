Uso de Pontos de Roteiro

• GARANTIR SUCESSO: Gaste 1 para sucesso automático ou +7 na rolagem.
• SOBREVIVER (Armadura de Roteiro): Gaste 1 para anular um ataque mortal.
• REESCREVER (Retcon): Gaste 1 para revelar item preparado, aliado ou fraqueza do vilão.
• PÁGINA DUPLA: Gaste 1–3 para aumentar o Grau de um poder (gera Condições depois).
• INTRODUZIR FATO: Gaste 1 para criar um detalhe conveniente no cenário.
* O uso gera Pontos de Edição para o Editor e pode acionar o Dado de Crise (1d6 vs pontos gastos).

Guia de Combate (Referência)

• ATAQUE (1 Ação): Teste de Precisão vs Defesa. Dano na Determinação. Múltiplos ataques: −5 cumulativo por ataque extra.
• BLOQUEIO (1 Ação): +1 Defesa por Tier até próximo turno.
• ESQUIVA (1 Ação): Teste de Agilidade vs Ataque para anular dano (não funciona vs área/psíquico).
• AJUDAR / MOVER (1 Ação): Auxilia aliado ou o move 1 Distância.
• DEFENDER (1 Ação): +3 Defesa para aliado, −3 para você.
• COBERTURA (1 Ação): Próximo ataque do inimigo contra aliado tem −5.
• DESARMAR (3 Ações): Teste Oposto para tirar arma.
• LIBERTAR (1 Ação): Teste para sair de amarras/agarrão.
• SUPERAR LIMITES (2 Ações): Marca Condição → recupera Determinação base do Tier.
• PÁGINA DUPLA (Sucesso Crítico): Supera Defesa por 10+ → dobra dados de Dano.
