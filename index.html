USO DE PONTOS DE ROTEIRO (PÁGS 6-9)

• GARANTIR SUCESSO: Gaste 1 para ter sucesso automático ou +7 na rolagem.
• SOBREVIVER (Armadura de Roteiro): Gaste 1 para anular um ataque mortal.
• REESCREVER (Retcon): Gaste 1 para revelar um item preparado, aliado ou fraqueza.
• PÁGINA DUPLA: Gaste 1-3 para aumentar o Grau de um poder (Gera Condições depois).
• INTRODUZIR FATO: Gaste 1 para criar um detalhe conveniente no cenário.
* O uso gera Pontos de Edição para o GM e risca o Dado de Crise (1d6 vs Pontos Gastos).

GUIA DE COMBATE (REFERÊNCIA)

• ATAQUE (1 Ação): Teste de Precisão vs Defesa. Dano na Determinação.
• BLOQUEIO (1 Ação): +1 Defesa por Tier até próximo turno.
• ESQUIVA (1 Ação): Teste de Agilidade vs Ataque para anular dano.
• AJUDAR/MOVER (1 Ação): Auxilia aliado ou o move 1 Distância.
• DEFENDER (1 Ação): +3 Defesa para aliado, -3 para você.
• COBERTURA (1 Ação): Atrapalha inimigo. Próximo ataque dele contra aliado tem -5.
• DESARMAR (3 Ações): Teste Oposto para tirar arma.
• LIBERTAR (1 Ação): Teste para sair de amarras/agarrão.
• SUPERAR LIMITES (2 Ações): Marca Condição para recuperar Determinação Base.
